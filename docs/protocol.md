# 阶段与数据协议

## 阶段

`collecting → awaiting_selection → reading → ready_for_slides → complete`

- `collecting`：明确课题、检索、维护候选库。
- `awaiting_selection`：候选库和导读完成，已在聊天中介绍，等待用户决定。
- `reading`：已有用户选择，正在获取全文、精读。
- `ready_for_slides`：所选文章均有已核验的精读记录，整理横向比较并制作 PPT。
- `complete`：实际 PPTX 及质量检查记录存在，交付条件通过。

`brief` 登记的文件应与聊天介绍一致；脚本不会替 AI 向用户讲解。新一轮候选集可在选文前导入，会回到 `collecting`。选文后如需补搜，建立同课题的新一轮目录并在 brief.md 链接上一轮，保留旧记录。用户重新选文可调用 `select`，这会清空精读登记及交付登记，但不删除笔记和 PPT 文件。要复用笔记，应再次核对后 `read` 登记。

## 文件职责

- `brief.md`：课题、关键问题、时间范围、纳入排除标准、读者、汇报时长、用户偏好。
- `search-log.md`：实际检索日期、平台、查询式、筛选理由、追溯引用的来源、覆盖缺口。没有执行的检索不能记成已执行。
- `papers.json`：候选元数据；同一论文的预印本与发表版本归并，保留版本说明。
- `briefing.md`：给用户的研究脉络、路线对照、候选短介绍、推荐理由和可直接回复的编号。
- `notes/Pxxx.md`：原文精读与证据定位。
- `synthesis.md`：所选文章横向比较、可比性边界、待解决问题以及对用户课题的启发。
- `slides/`：大纲、PPTX、渲染预览、QA 记录、必要的讲稿文件。
- `state.json`：CLI 维护的状态、用户选择原话、时间、登记文件及摘要校验值。时间为 UTC ISO 8601。

## 候选论文数据

导入文件为 JSON 数组。必填：`id`、`title`、`url`、`evidence_level`。ID 格式为 `P001`，可超过三位；一旦介绍给用户就保持稳定。正文引用使用相同 ID。

```json
[
  {
    "id": "P001",
    "title": "此处填写核实过的真实论文标题",
    "url": "https://doi.org/实际DOI",
    "doi": null,
    "authors": [],
    "year": null,
    "venue": null,
    "evidence_level": "abstract",
    "route": "方法路线",
    "problem": "论文解决的问题",
    "idea": "核心方法",
    "relevance": "与本课题的关系",
    "why_read": "推荐精读的具体理由",
    "limitations": "初筛能支持的判断",
    "code_url": null,
    "version_note": "版本信息"
  }
]
```

以上仅为字段示意，不能当作真实论文导入。`evidence_level` 只能为 `metadata`、`abstract`、`full_text`，表示初筛实际读取的材料范围，不等于已精读。未知字段用 null 或明确注明未核实，不要补造作者、会议或数值。DOI 先去除网址前缀并转小写用于去重，标题按大小写与空白归一去重；其余相近标题由 AI 人工核对版本。

## 精读与比较

每篇笔记应包括：一句话定位、研究动机、基本思路、方法机制、关键公式及符号、必要假设、实验设计、结果证据、贡献、局限、复现入口与课题启发。篇幅取决于论文，不能只填模板。

记录全文来源和版本。关键结论附 Section、页码、Figure 或 Table，能核实到哪种粒度就写哪种，不编造定位。区分作者结论、自己推断和待验证假设。遇到扫描 PDF，先抽取或 OCR，再目视核对关键图表、公式。

横向比较至少考虑问题设定、输入和监督条件、方法、数据集、指标、基线、算力成本及证据范围。不同数据集或评估协议的数字不能直接排出优劣；保留数值的单位、指标方向、评估条件和原文定位。

## PPT 交接

默认中文、16:9、约 15 分钟，页数随内容调整。用户给定时长、页数和模板优先。内容围绕研究问题、路线演化、所选文章机制和实验、横向比较、可验证的研究机会组织。

每页研究性结论附论文 ID；备注给出可追溯的完整来源与图表位置。保留证据边界和必要条件。假设或建议要明确标为推断。未精读候选可以作为有来源的背景，但不能包装成已完成精读的发现。

最终交付真实可编辑 PPTX。逐页渲染检查中文字体、公式、溢出、图表清晰度、来源和演讲节奏。`slides/qa.md` 记录实际工具、预览位置、已查问题与修复，以及仍影响使用的限制；没有检查不能写成通过。仅有大纲或工具导出失败时不执行 `complete`。
