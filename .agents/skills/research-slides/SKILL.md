# 文献调研 PPT

读取本仓库 `docs/protocol.md`、run 的 `brief.md`、`synthesis.md`、所选论文笔记及状态。执行 `python scripts/workflow.py check <run>`，处理缺失或过期笔记后再推进交付。

优先使用当前环境的 Presentations 技能和对应制作工具，并遵循用户模板。没有该技能时使用环境已有的 PPTX 制作库或演示文稿连接器：先确认其导出和渲染能力，再创建文件。不要绑定开发者机器的路径、私有工具名或密钥。若缺少制作或渲染能力，保存内容、证据和大纲，说明需要的能力，不宣称 PPT 已完成。

先在 `slides/outline.md` 组织叙事：研究问题、路线及演化、所选论文的关键机制、实验发现、横向比较、研究机会和参考文献。页数由用户要求和汇报时长决定。每页有明确问题或结论，避免按文章机械复制摘要。未精读候选只作来源明确的背景。

中文内容、16:9 为默认。优先保留可编辑文本、表格与数据图。原文图表清晰裁切并注明来源；概念示意图不能伪装成论文原图或实验结果。公式过长则拆页，不以缩小字号解决所有拥挤。

每页关联论文 ID，备注记录引用 URL、原文位置和讲解要点，末尾给完整参考文献。结果比较保留单位、数据集和评估设置；解释不能直接比较的情况。为提出的研究方向区分已有证据和未来假设。

导出真实 PPTX 至 `slides/review.pptx`，渲染并查看每页，修复中文乱码、溢出、重叠、公式错误、图表模糊和引用断链。将真实检查方法及预览位置写入 `slides/qa.md`，必要时单独保存讲稿。不能把未渲染的大纲或文件存在性检查当作视觉检查。

全部完成后执行：

```text
python scripts/workflow.py complete <run> --deck slides/review.pptx --qa slides/qa.md
```

给用户提供最终 PPT 与笔记的真实可点击链接。需要外部发布时以用户对研究成果的授权为准；源代码上传授权不包含发布本次研究材料。
