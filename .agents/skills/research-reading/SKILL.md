# 所选论文精读

读取本仓库 `docs/protocol.md` 及 run 的状态。必须已有真实用户选择。没有选择时回到 `../research-briefing/SKILL.md`；不得自行把候选全部视为已选。

逐篇获取选定版本的原文，先理解摘要、动机与结论，再梳理方法、必要假设、核心公式与算法，最后核验实验、图表、消融和对比条件。全文不可访问时保存获取进展，继续其他文章；仅有摘要不能登记为完成精读。

按协议将笔记写到 `notes/Pxxx.md`。围绕“为什么需要这个工作、基本想法如何成为具体机制、证据支持了什么、对当前课题有何用处”组织。对关键机制给出足够细节，保持符号、单位、指标方向和适用条件。论断、公式、图表附可核实的原文定位；明确区分作者主张和自己的判断。

若环境已有 paper-deep-reading 或 PDF 能力，可复用其读取和分析方法；本技能自身已提供完整流程，不依赖该技能存在。保持本 run 的文件结构、选文边界和用户指定的分享范围。

完成一篇、核实来源后执行：

```text
python scripts/workflow.py read <run> --id P001 --note notes/P001.md --source <实际全文网址或实际本地路径>
```

整理 `synthesis.md`：方法谱系、可比条件、核心发现、具体局限和可检验的后续问题。不要将不同数据集的最好分数排列成统一榜单。针对用户关注点讨论方法、成本、复现条件或研究机会，而非重复每篇摘要。

运行 `check`，待所选文章均完成后，按任务范围交付笔记或继续 `../research-slides/SKILL.md`。如果用户要求 PPT，则继续制作，无需再次询问是否开始。
